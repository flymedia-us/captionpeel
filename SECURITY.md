# Security Policy

## Supported versions

Security fixes are provided for the latest published CaptionPeel release.

| Version | Supported |
| --- | --- |
| 1.0.x | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public issue.

Use **Security → Report a vulnerability** in this repository to open a private report visible only to the reporter and maintainers. Include:

- A description of the issue and its potential impact
- Reproduction steps or a proof of concept
- The affected CaptionPeel and macOS versions
- Any suggested mitigation

You can expect an initial acknowledgment within seven days. Ordinary bugs and feature requests belong in GitHub Issues.
