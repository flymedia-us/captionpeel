# App Privacy response

Use this response for the initial CaptionPeel release, provided the distributed build contains only the code in this repository and no analytics, crash-reporting, advertising, or other third-party data collection is added.

- Does this app or third-party partners collect data from this app? **No, we do not collect data from this app.**
- Tracking: **No.**
- Privacy Policy URL: `https://apps.flymedia.us/captionpeel/privacy/`

Rationale: CaptionPeel processes only video files the user explicitly chooses, runs text recognition locally with Apple frameworks, and writes an SRT only when the user chooses a destination. It has no account, network service, analytics, diagnostics upload, advertising, or tracking. This is consistent with [`docs/privacy-policy.md`](../docs/privacy-policy.md) and [`CaptionPeel/PrivacyInfo.xcprivacy`](../CaptionPeel/PrivacyInfo.xcprivacy).

Reconfirm this declaration whenever dependencies or network behavior change.
