# App Store launch packet

This directory contains the copy and review information for the first macOS App Store release of CaptionPeel. The source of truth for the app’s bundle ID, version, category, sandboxing, and privacy manifest remains [`project.yml`](../project.yml).

Before creating the App Store Connect record, use the values in [`metadata/en-US.md`](metadata/en-US.md), complete the App Privacy response in [`privacy.md`](privacy.md), and paste [`review-notes.md`](review-notes.md) into App Review Information.

Screenshots are intentionally not included. Add one to ten macOS screenshots for the `en-US` product page before submitting.

The remaining account-bound choices are documented in [`launch-checklist.md`](launch-checklist.md). They require an App Store Connect user with the appropriate role and must be decided by Fly Media.
